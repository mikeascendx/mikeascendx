## Design Rules

- No emojis anywhere in the document
- Max 2 animated GIF dividers total
- No GIF aesthetic grid at the bottom
- No "Kaizen" word
- No non-functioning widgets
- Badges use shields.io with dark bg and cosmic accent colors
